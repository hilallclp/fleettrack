# 🚗 FleetTrack - Fleet Management System

FleetTrack is a full-stack fleet management system developed using React, PHP, and MySQL.

## 🔧 Technologies Used

* React.js
* PHP
* MySQL
* AMPPS

## 🚀 Features

* User login system
* Role-based panels (Admin, Driver, Technician)
* Vehicle management
* Maintenance tracking

## 📂 Project Structure

fleettrack
├── src (React frontend)
├── api (PHP backend)
├── Database

## ⚙️ How to Run

1. Put API files into AMPPS:
   /Applications/AMPPS/www/fleettrack

2. Start AMPPS:

   * Apache ✅
   * MySQL ✅

3. Run React:
   npm install
   npm start
